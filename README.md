# Proyecto

La ejecución de Dijkstra + Greedy se realiza por etapas independientes. Consulte [la guía de comandos](dijkstra_greedy/README.md).

- `cgra/`: simulador, operaciones y skills, compartidos con la solución RL.
- `dijkstra_greedy/`: la solución Dijkstra + Greedy (etapas, paquete `dijkstra`, configuración y pruebas).

Pruebas:

```bash
python3 cgra/test/run_tests.py             # simulador
python3 dijkstra_greedy/tests/run_tests.py  # Dijkstra + Greedy
```
