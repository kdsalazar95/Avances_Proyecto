# Estructura del directorio de la Tarea 1

En este directorio se utilizan los algoritmos de Dijkstra y Aprendizaje Reforzado (RL: _Reinforce Learning_) para resolver el problema del Viajero _Travelling Salesman Problem_ como metodos de optimizacion.

El directorio tiene la siguiente estructura:



- ``CGRA``: contiene el plan de pruebas tanto a niver de requisitos por prueba como ejemplos de la implementacion de las pruebas en codigo.
Tembien contiene la estructura interna del PE del simulador de la CGRA.

- ``comun``: contiene la representacion mediante un grafo del problema del viajero. Este grafo se utiliza tanto para el algoritmo de Dijkstra como para el algoritmo de RL.

- ``Dijkstra`` contiene los scripts que se utiilizan para resolver el problema del viajero con Dijkstra.

- ``Tests``: contiene los tests que se utilizaron para pobrar individualmente los scripts para verificar su debido funcionamiento.

- ``RL`` Contiene los scripts que se utilizan para resolver el problema del viajero con RL como segundo metodo de optimizacion.
